# Changelog

## 2.0.0-alpha.1

P0 evidence-engine experiment based on the independent v1.9 systems audit.

### Design brain

- compressed the default SKILL.md from a stage-heavy handbook into a task router
- added explicit module ownership and progressive-disclosure routing
- added real-content-first structural modeling
- added compact interaction contracts for consequential or ambiguous behavior
- integrated Behavioral Craft into Experience Dynamics without fixed Apple-style physics values
- clarified that familiar patterns are valid when they reduce error or learning cost
- clarified that cross-product similarity is evidence, not automatic failure

### Evidence engine

Added a small Node/Playwright tool surface:

- `ui-slop inspect`
- `ui-slop evidence`
- `ui-slop validate`

The evidence runner can collect:

- responsive screenshots
- ARIA snapshots
- event traces
- focus traces
- reduced-motion variants
- typography distribution
- interactive geometry
- animation inventory
- runtime and console errors
- product-specific assertions for route, state, visibility, text, storage, and reload behavior
- checksums and an evidence-first review packet

### Finding model

- `hard_failure`: explicit contract or applicable verifiable standard failed
- `advisory`: measured risk requiring product judgment
- `evidence_only`: neutral inventory
- `blocked`: required evidence unavailable

Aesthetic frequency metrics do not become hard failures.

### Research discipline

Added `research/v2-benchmark-protocol.md` for predeclared no-skill / v1.9 / v2 / Impeccable comparisons and v1.9-versus-compressed-router ablation.

### Deliberately not built

- no industry-to-style catalog
- no aesthetic quality score
- no global motion/spring/spacing recipe
- no cross-product originality score
- no `compare`, `lab`, or `learn` command in P0

## 1.9.0

Final planned 1.x convergence cleanup.

Fresh v1.8 testing across Research, Travel, Creative, and Operations showed interaction topology varying by domain while a repeated warm-paper / dark-ink / thin-rule visual material world remained.

v1.9 added second-order visual convergence checks, layout-explanation copy restraint, direct-manipulation opportunity review, and motion-causality QA without adding a fixed aesthetic or motion recipe.
