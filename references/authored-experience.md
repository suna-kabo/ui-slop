# Authored Experience

A usable interface can still feel machine-generated.

This layer makes the product feel cared for, authored, and worth spending time in.

## Intended feeling

For substantial visual work, decide what the user should feel.

Examples:

- calm and in control
- curious and rewarded for exploring
- energetic and playful
- focused and precise
- intimate and personal
- collectible and desirable
- expressive and creative
- premium and deliberate

Let the feeling affect:

- typography
- motion
- density
- imagery
- surfaces
- transitions
- empty states
- hover states
- section rhythm

## Browsing pull

For stores, media libraries, fandom/community sites, portfolios, travel discovery, creative archives, and other Browse / Collect surfaces, optimize for **continued curiosity**.

Useful mechanisms:

- visible next interesting targets
- collection rhythm
- dense/quiet contrast
- previews and peeks
- meaningful hover reveals
- contextual transitions
- art-led category changes
- saved/favorite continuity
- related-item paths
- collection/character relationships

Do not turn this into manipulative infinite-scroll mechanics.

## Human care appears in edge states

Care often shows up where templates stop:

- selected state matches the object
- hover reveals useful content
- transitions preserve origin/context
- empty states fit product voice
- long names are actually handled
- icons share a drawing language
- imagery crops intentionally
- disabled controls remain understandable
- loading preserves structure
- mobile changes interaction instead of stacking desktop

## Detail density

Detailed does not mean busy.

Cared-for products may use:

- micro-typographic contrast
- custom separators
- subtle textures
- contextual illustration
- meaningful motion
- layered depth
- varied section rhythm
- content-specific affordances

Each detail should reinforce subject, hierarchy, discovery, state, or interaction.

## Signature moments

Identity-heavy products may use one to three authored moments.

Examples:

- navigation reacts to media state
- a collection transition changes the visual world
- selected artwork expands into a workspace
- route motion traces itinerary order
- a catalog opens like a spread
- progress uses a domain object instead of a generic spinner

A signature moment is not random animation.

## Avoid design performance

These often look like the model trying to prove it designed something:

- inspirational slogans inside work tools
- eyebrow labels everywhere
- clever microcopy without utility
- decorative charts
- arbitrary badges
- over-produced empty space
- gradients without subject connection
- tiny uppercase text as default hierarchy
- rounded controls chosen only because they look modern

The interface should feel authored, not self-conscious.

## Return test

Ask:

- Would I enjoy opening this again tomorrow?
- Does it reward attention without demanding it?
- Is there something to notice after the first five seconds?
- Does character reveal itself through use?
- Could a fan/community recognize care in the details?

If not, the interface may be correct but emotionally flat.
