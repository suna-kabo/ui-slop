# Art Direction and Media

Use this when the product contains artwork, products, characters, travel imagery, media, album art, photography, illustration, or other visually meaningful content.

## Media can shape structure

Do not automatically shrink rich visual content into thumbnails inside generic cards.

Consider media as structural material:

- full-bleed crop
- object cutout
- collection backdrop
- layered depth
- poster composition
- catalog spread
- art-led navigation
- media-driven transition
- contextual texture/pattern
- responsive focal crop

## Build a crop system

Define how imagery behaves:

- aspect ratios
- focal point
- object-fit
- safe text area
- mobile crop
- hover/detail crop
- low-resolution fallback

Do not rely on lucky source-image composition.

## Art and UI should share a world

When a product has strong art direction, connect UI details to it through:

- typography
- geometry
- color
- separator language
- motion
- icon style
- texture
- layering

Do not paste art behind a generic SaaS interface and call it branded.

## Fandom / game / creative products

These products can tolerate more identity than a banking or admin tool.

Useful patterns may include:

- collection-specific visual worlds
- character/album/project accents
- animated transitions tied to content
- bespoke navigation
- playful but readable affordances
- richer hover/detail states
- collectible presentation
- poster/catalog rhythm

Do not confuse personality with visual noise.

## Product/store browsing

For merchandise and collectible stores:

- show why an item belongs to a collection
- expose related character/series/drop paths
- make preorder/release/stock state clear
- preserve browsing context when inspecting an item
- vary layout rhythm instead of one endless product-card grid
- let campaign art lead when it has real value

## Performance

Visual richness still needs:

- responsive images
- lazy loading where appropriate
- restrained animation cost
- sensible decoding/loading
- stable layout
- reduced-motion handling

Do not use a large background video merely to seem premium.

## Accessibility

Media needs:

- meaningful alternative text where informative
- decorative treatment hidden from assistive tech where appropriate
- sufficient text contrast
- non-color state cues
- keyboard-accessible media controls
- pause/stop control for meaningful auto-motion where required
