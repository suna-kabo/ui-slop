# AI Fingerprint Gate

Run this before final acceptance.

No single pattern is automatically wrong.

A cluster without product justification indicates generated-interface convergence.

## Composition fingerprints

Watch for:

- eyebrow + giant headline + explanatory subtitle
- centered/left hero before a work surface
- generic KPI strip
- generic main + right rail
- right-side rounded inspector
- top-right floating segmented control
- universal max-width shell
- equal-weight card grid
- large empty intro before the task
- desktop columns simply stacked on mobile

## Component fingerprints

Watch for:

- every control using the same radius
- pills for navigation, status, filter, optionality, and actions
- icon-in-circle everywhere
- universal border + soft shadow cards
- generic top-right search
- progress donut because it looks dashboard-like
- sparklines without decision value
- badges added just to make rows look richer
- chevron at the end of every row

## Copy fingerprints

Watch for:

- tiny uppercase eyebrow on every section
- secondary labels that merely restate what the layout, navigation, or control already communicates
- helper descriptions whose only job is to explain an obvious region
- slogan-like headline inside work software
- helper sentence under every heading
- "Your X, all in one place"
- "Everything you need to..."
- obvious interaction instructions
- fake editorial prose added for design atmosphere
- filler motivational language

## Visual fingerprints

Watch for repeated material worlds, not only repeated palettes.

Examples include dark-neon technical shells, pastel-card SaaS, glass/glow premium surfaces, or paper/editorial/archival instrument worlds built from off-white fields, dark ink, thin rules, and restrained signal colors.

They may be correct once. Repetition across unrelated work is the warning.

A product can fail this gate even when its layout silhouette is different if its material sentence, typography voice, surface treatment, and accent logic are substantially the same as unrelated recent outputs.

## Typography fingerprints

Watch for:

- convenience system fonts used without product reason
- the same rounded humanist sans across unrelated products
- neutral sans + mono for every data product
- oversized bold sans headline as the main identity
- tiny uppercase metadata doing too much hierarchy work
- condensed uppercase + tracking used for unrelated secondary roles
- most visible working copy collapsing into microtype

## Interaction fingerprints

Watch for:

- every hover lifts, enlarges, brightens, or only changes background
- every product image zooms on hover
- every detail uses the same fade + small translate
- every selected row gets the same accent stripe
- every mobile detail becomes the same bottom sheet
- every route uses the same directional slide
- every state change uses the same easing/duration family
- interaction personality comes from effects rather than domain behavior
- unrelated products can be described with the same interaction sequence

## Behavioral silhouette comparison

Compare against unrelated recent outputs.

Ignore visual styling and describe only:

- hover/focus behavior
- selection behavior
- detail entry/exit
- related-object traversal
- mode switching
- responsive interaction transformation
- Back/return behavior

If that description is substantially reusable across unrelated products, investigate interaction convergence.

Read `experience-dynamics.md` before choosing replacement mechanics.

## Static silhouette comparison

Mentally remove text, color, imagery, and branding.

If the layout silhouette remains substantially the same as unrelated work, investigate structural convergence.

## Visual-world comparison

Now ignore layout and describe only the visual material system:

- surface metaphor
- color temperature / contrast
- typography voice
- rule / border / elevation language
- imagery / texture strategy
- accent logic

If the same description fits several unrelated products, investigate second-order visual convergence even when the layouts are different.

Return to `visual-direction.md` and explore a materially different candidate rather than recoloring the same world.

## Decision

If several fingerprints appear without strong product reasons:

1. identify whether the convergence is structural, visual-material, typographic, semantic, or behavioral
2. return to the corresponding design stage
3. replace the underlying logic, not merely the styling token
4. rerun the relevant silhouette comparison

Do not solve structural slop by changing accent hue.

Do not solve behavioral slop by changing duration, easing, or slide direction while keeping the same interaction model.
