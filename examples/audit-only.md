# Example: Audit-only request

Use `ui-slop` to audit this product UI.

This task is analysis only.

Do not modify code, files, repository state, deployment settings, or product behavior.

Run or inspect the actual rendered product when possible. Review the primary workflow, hierarchy, layout, typography, density, responsive behavior, interaction affordances, motion, accessibility, performance signals, unnecessary copy, and generic AI-generated patterns.

Distinguish:

- product-contract problems
- information-architecture problems
- visual-system problems
- interaction problems
- responsive problems
- accessibility/performance problems
- minor polish issues

Prioritize findings by user impact.

Do not prescribe a ground-up rebuild unless the evidence actually supports one.
