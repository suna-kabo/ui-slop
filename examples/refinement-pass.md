# Example: Final refinement pass

Use `ui-slop` for a final refinement pass.

The current design direction is approved. Do not redesign it again.

Inspect the real product at desktop and mobile widths and identify only material issues involving:

- density
- spacing
- hierarchy
- scan speed
- typography
- interaction feedback
- inspector composition
- unnecessary copy
- motion quality
- accessibility
- performance

Prefer composition fixes over adding new cards, decoration, charts, gradients, icons, or helper text.

Preserve the current design system and make the smallest changes required to move the UI from good to production-quality.
