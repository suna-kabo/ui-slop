# UI Slop 3.0.0 release notes

Install the Codex skill from the checkout with `npm ci` and `npm run skill:install:user`. Project installs, portable packaging, and read-only diagnostics are available through the corresponding `skill:` commands. The bundled evidence tools use Playwright and can run without a Codex browser integration or custom MCP.

The five-stage workflow requires a runnable vertical proof and SELECT decision before full implementation. It records separate problem, solution, and implementation reviews. Readiness requires executed evidence and a rendered qualitative review, including supporting-copy subtraction across three states.

See the [installation instructions](README.md) and [validation report](VALIDATION-REPORT.md).
