# Benchmark Corpus

This corpus is intentionally heterogeneous. It tests whether the design process adapts to product structure instead of repeating one visual shell.

Each task has a protected product contract and realistic edge-distribution data. The fixtures are content/data fixtures, not visual templates.

- **casewire**: investigative claim, source, contradiction, and provenance work
- **waypoint**: spatial/time itinerary planning with replacements and timing conflicts
- **cutroom**: creative sequence editing with alternate takes, reorder, undo, and persistent notes
- **opswatch**: operational triage, failure recovery, retry acknowledgement, and return to filtered work
- **collection**: browse/collect/compare with provenance, seller detail, and changed availability

Do not tune the skill against these five tasks and then treat the same corpus as independent proof. They are the predeclared RC2 evaluation set and should be supplemented by new holdout tasks in later rounds.
