# Kiln scheduling
Build a responsive shared kiln scheduling and firing-management tool for a community ceramics studio. Members submit work for firing, check estimated scheduling and progress, and avoid incompatible clay or glaze combinations. Studio staff organize kiln loads, manage capacity and firing programs, resolve conflicts, inspect demand, and update firing progress. The product must support real workflows with realistic representative content, responsive desktop/mobile experiences, state continuity, keyboard operation, and recovery paths.

For a comparable vertical slice, let a user inspect a loaded kiln and its actual pieces, select compatible work, reserve it, cancel if mistaken, and see the resulting capacity and cross-day occupancy. Use at least two loads and one long work name. Begin with the schedule.

# Local listening
Build a responsive local live-music discovery tool for a person deciding what to see this weekend. They can explore performances, check venue or access details, save a shortlist, and revisit it later.

For a comparable vertical slice, show at least three varied performances with realistic details. Open performance detail, save or unsave, return to discovery and continue there, then revisit the shortlist. Begin on discovery.
